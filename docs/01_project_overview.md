# 프로젝트 개요

## 한 문장 소개

**CLOUDWASH는 AI 번호판 인식을 차량 입차·예약·세차·결제·출차와 관리자 검수에 연결한 무정차 자동 세차 운영 소프트웨어 프로토타입이다.**

실제 차단기·세차기 하드웨어는 연결하지 않았으며, 웹 화면과 API 요청으로 장비 이벤트와 상태 전이를 시뮬레이션했다. 하드웨어 연동은 라즈베리파이 등 제어 장비가 확보된 이후 확장할 과제로 남겼다.

## 프로젝트 배경

무인 세차장은 차량 식별, 예약 확인, 세차 진행, 결제와 출차가 끊김 없이 이어져야 한다. 그러나 각 기능이 별도로 동작하면 고객은 반복해서 차량 정보를 입력해야 하고, 운영자는 차량 상태와 결제 여부를 여러 시스템에서 확인해야 한다.

번호판 OCR만 도입해도 문제가 완전히 해결되지는 않는다. 인식 오류가 차량 정보와 입차 이력에 반영되면 이후 세차·결제·출차 데이터까지 잘못 연결될 수 있기 때문이다. 따라서 AI 모델의 정확도뿐 아니라 오류를 발견하고 복구하는 운영 흐름이 필요하다.

## 목표

- 번호판을 기반으로 차량을 자동 식별한다.
- 회원·비회원과 예약·현장 차량을 하나의 입차 흐름에서 처리한다.
- 입차·세차·결제·출차 상태의 잘못된 전이를 차단한다.
- 운영자가 OCR 결과를 검수하고 교정할 수 있게 한다.
- 교정된 데이터를 재학습 후보로 축적한다.
- 고객, 사업주와 관리자가 각 역할에 맞는 기능을 사용하게 한다.

결제는 회원의 충전 잔액 자동 차감과 비회원·잔액 부족 회원의 별도 결제 흐름을 지원한다. 사업자등록이 필요한 카드·PG 기반 외부 자동결제는 구현 범위에서 제외했다.

## 사용자

| 사용자 | 주요 기능 |
|---|---|
| 고객 | 회원가입, 차량 등록, 세차장 탐색, 예약, 결제, 이용 내역 |
| 비회원 | 번호판 기반 현장 이용, 이용 내역 조회, 사후 결제 |
| 사업주 | 세차장·장비·영업시간, 예약, 세차 이력과 정산 관리 |
| 관리자 | 회원·차량·결제·문의·세차장 관리, OCR 검수, 예지보전 확인 |

## 주요 업무 흐름

### 차량 이용

```text
세차장 탐색
  → 예약 또는 현장 방문
  → 입차 카메라 촬영
  → 번호판 검출·인식
  → 차량·예약·블랙리스트 확인
  → 입차 기록
  → 세차
  → 결제
  → 출차
  → 이용 내역·정산 반영
```

### OCR 개선

```text
번호판 이미지
  → YOLO 탐지
  → OCR 추론
  → 결과·신뢰도·좌표 저장
  → 관리자 검수
  → 번호판/bbox 교정
  → 학습 후보 지정
  → 재학습 데이터 Export
```

## 시스템 범위

### 고객·사업주 웹

- 인증·인가 및 역할별 라우팅
- 차량, 세차장, 예약, 결제와 세차 내역
- 지도·날씨·소셜 로그인 등 외부 서비스 연동

### 관리자 웹

- 회원·차량·블랙리스트
- 결제·환불·정산과 문의
- 세차장·장비·운영 내역
- 번호판 OCR 로그와 교정
- 예지보전 상태와 시연 모드

### 업무 백엔드

- JWT 기반 인증과 역할별 API 보호
- MyBatis와 PostgreSQL 기반 업무 처리
- 차량과 세차 상태 불변조건
- OCR·예지보전 FastAPI 호출
- 외부 API와 결제 서비스 연동

### AI 서버

- YOLO11s 번호판 검출
- Lite050 CNN+CTC 문자 인식
- Beam5+Format decoder
- 예지보전 추론 API

## 개인 역할

개인 역할은 OCR 데이터·모델 개발과 AI 서비스 연동을 중심으로 한다.

- AI Hub·Roboflow·광안대교 실사 데이터 통합
- 데이터 감사, 분할과 품질 분석
- OCR 구조별 학습·비교와 최종 모델 선정
- FastAPI OCR 서버와 Spring 연동
- OCR 로그·검수·재학습 데이터 관리
- Gate 입차·세차·출차 상태 제어
- 차량 등록·중복 방지·논리 삭제·블랙리스트
- 테스트 및 통합 안정성 개선

예지보전은 담당 기능으로서 실험 결과를 검토해 모델을 선정하고 서비스에 통합한 경험으로 설명한다. 데이터는 선도기업 에스트래픽 실무 담당자가 프로젝트용으로 제공한 합성 센서 데이터이며, 실제 장비 운영 성능으로 주장하지 않는다. 저장소에서 정식 비교가 확인되는 범위는 로지스틱 회귀 v1·v2와 OCSVM 보조 탐색이며, 확인되지 않은 딥러닝 모델 비교를 주장하지 않는다.

## 프로젝트가 보여주는 역량

- AI 실험을 동일한 평가 조건으로 관리하는 능력
- 모델을 API와 업무 데이터에 연결하는 능력
- 정상 흐름뿐 아니라 운영 예외와 데이터 정합성을 설계하는 능력
- AI 오류를 사람이 복구하고 다시 데이터로 축적하는 운영 관점
- 팀원의 결제·지도·인증 기능과 인터페이스를 맞추는 협업 능력
