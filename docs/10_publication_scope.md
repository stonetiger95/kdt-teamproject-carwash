# 데이터와 소스 공개 범위

## 공개 자료

- 데이터 개수와 분할 방식 등 집계 정보
- 정확도, PR-AUC, 오류 수와 오경보 등 집계 성능 수치
- 직접 작성한 시스템 구성도와 처리 흐름
- 개인 식별정보가 없는 도표
- 민감정보와 내부 경로를 제거한 백엔드·프런트엔드·AI API 소스와 테스트
- 실제 값을 제거한 `.env.example`

## 비공개 자료

- AI Hub 원본 번호판 이미지와 라벨
- Roboflow 원본 이미지와 bbox 라벨
- 에스트래픽이 제공한 광안대교 실사 이미지
- 에스트래픽이 제공한 프로젝트용 예지보전 합성 센서 원본
- 차량 번호, 사용자 계정과 결제 정보가 포함된 화면·로그·DB 덤프
- API 키, 비밀번호, 토큰과 내부 접속 정보
- 재배포 조건을 확인하지 않은 모델 가중치

공개 소스는 설계와 구현을 검토하기 위한 포트폴리오 버전이다. 비공개 데이터와 모델 가중치가 필요하므로 저장소만으로 전체 추론 결과를 재현하거나 실제 서비스를 배포할 수는 없다.
