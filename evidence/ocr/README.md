# OCR 공개 수치 검증 기록

이 폴더는 포트폴리오 README에 사용한 OCR 수치의 범위와 출처를 정리합니다. 원본 번호판 이미지와 라벨은 이용 조건과 개인정보 보호를 위해 공개하지 않습니다.

## Locked test

- 실행일: 2026-07-21
- 평가 데이터: 학습·튜닝과 분리한 실환경 번호판 Crop 1,000장
- 평가 단위: 번호판 전체 문자열 완전 일치
- Lite050 + Beam5/Format: 971/1,000, 97.1%
- STN-CRNN + Greedy: 937/1,000, 93.7%
- 범위 제한: YOLO 번호판 탐지를 포함한 end-to-end 정확도가 아님

`locked_summary.csv`는 최종 평가 결과의 집계본이고, `model_profile.csv`는 같은 실행에서 기록한 모델별 파라미터 수입니다.

## 데이터 수량

AI Hub 90,000장 manifest에서 `^\d{2,3}[가-힣]\d{4}$` 형식에 맞는 1줄 정규 번호판을 다시 집계했습니다.

- 학습 원본 80,000장 중 55,103장
- 검증 원본 10,000장 중 6,819장
- 합계 61,922장

실환경 manifest는 학습·검증 9,000장과 locked test 1,000장으로 분리되어 총 10,000장입니다.

YOLO Hard Sample은 세 라벨 묶음 200장, 200장, 332장으로 구성되어 총 732장입니다. 기존 학습 데이터 8,529장에 합쳐 통합 학습 데이터는 9,261장이 되었습니다. 전체 데이터에 대한 전후 탐지 성능 향상률은 산출하지 않았습니다.

## 버전 구분

대표 수치 97.1%는 원본 locked test 결과입니다. 정답 또는 Crop 교정이 반영된 corrected-v2 결과는 데이터 버전이 다르므로 대표 수치와 합치지 않습니다.
